# DoD Assessment & Authorization Career Guide

A practitioner’s guide to DoD assessment and authorization, covering the Risk Management Framework (RMF), Authority to Operate (ATO), and eMASS.

**Author:** Ebubeze “Eze” Anene, CISSP

## Read the guide

[**Cyber Career Guide — DoD Assessment & Authorization (RMF, ATO, eMASS)**](<Cyber%20Career%20Guide%20-%20DoD%20Assessment%20%26%20Authorization%20%28RMF%2C%20ATO%2C%20eMASS%29.md>)

Written for experienced IT and cybersecurity practitioners moving into DoD authorization work, and ISSOs and ISSMs preparing for their next role.

The guide covers:

- The RMF lifecycle, authorization types, and eMASS workflows
- ATO package artifacts, control baselines, STIGs, and ACAS
- Practical assessment lessons and residual risk statements
- Career paths, certifications, hands-on labs, and a 60-day repositioning plan
- Public reference documents and tools

The Markdown file retains its original contents. References written as `[[Page Title]]` point to related notes in the author’s Obsidian vault; those notes are not included in this repository.
